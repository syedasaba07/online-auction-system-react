# Online Auction System - React + Vite

This project is the React + Vite version of the original Online Auction System.

## Requirements implemented
- React + Vite
- User module: registration, login, dashboard, live auctions, bidding, my bids
- Admin module: admin login, add auction, manage/delete auctions
- Local Storage for user account, login state, admin login state, auctions and bids
- Client-side protected routes

## Run locally
```bash
npm install
npm run dev
```

Open the localhost URL shown by Vite.
